# CHANGELOG

## Unreleased

- Генерация с подбором (`regen`) приведена к `do_awg_gen check` из Zapret-Manager:
  цепочка API Cloudflare (4 эндпоинта), фаза портов с запасными, порядок масок
  (MIXOMO первой), приёмка по трафику и не-torn, RU-точка как рабочая,
  фолбэки handshake/стандартная в ручном режиме.
- Исправлено: регистрация через живой туннель и boot-туннель передавали
  `--interface <имя>` одним аргументом, и `curl` его не принимал; boot-туннель
  теперь остаётся поднятым на время регистрации.
- Авто-режим (`run`) не пишет фолбэки без трафика.
- Исправлено: внешний генератор ключей никогда не вызывался (`WARP_PRIMARY`
  затирался пустой переменной); откат UCI удаляет пустые опции вместо записи
  `opt=`.

## 0.1.0-1

- Первая версия: страница LuCI (статус, настройки, ручные операции, лог),
  автопроверка по расписанию (крон, часовой тик, интервал N часов), автозамена
  нерабочего WARP-конфига генерацией с подбором точки входа и маски, бэкап и
  автооткат, защита от ложных срабатываний (WAN-предпроверка, повторы), lock.
